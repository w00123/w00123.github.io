使用说明：

  1. 下载模板：点击左侧图标下载 Excel 模板文件。
  2. 填写信息：按表格示例填写服务器内网IP、公网端口、虚拟IP、内网端口、IPS规则库名称。
    • "公网端口"用英文逗号分隔（如：80,2001-3001,443）。端口范围格式：起始-结束。
    • "公网端口"和"内网端口"都留空 → 全端口映射。
  3. 上传文件：点击右侧"选择文件"上传填好的 Excel。
  4. 下载配置：系统自动生成山石防火墙配置（.txt），通过 CLI 窗口运行。
  5. 非初始化配置请谨慎使用，建议提前导出备份，否则可能覆盖旧策略。
注意：请确保 Excel 格式正确，严格按照模板填写。目前仅支持 TCP 端口。

功能清单

  1. 厂家要求配置
    • 开启端口扩展 · TCP超时调整 · 关闭序列号检测
    • 入侵防御模板 IPS · 日志管理 · 监控配置
    • IP信誉过滤 · 密码复杂度 · NTP时间同步
    • untrust域安全策略 · 日志策略
  2. 服务对象：支持创建、合并、去重端口（仅 TCP）。
  3. DNAT：支持多端口、端口范围、端口转换、全端口映射；自动合并去重。
  4. SNAT：自动为每个内网IP生成一条SNAT策略。
  5. 安全策略：入向/出向策略 + IPS防护，自动去重。
