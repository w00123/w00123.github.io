indexnow自动提交脚本

发表于2026-07-07|更新于2026-08-16|hexo博客
|阅读量:

介绍

IndexNow 是 Bing 等搜索引擎联合推出的实时索引协议，hexo的插件已经老了，装上之后直接报错，所以干脆整了一个脚本上传。

该脚本可以从 sitemap.xml 自动提取所有 URL，批量提交到 IndexNow。纯 Python 标准库。

  • 从 sitemap.xml 递归提取所有 URL（支持 sitemapindex 嵌套）
  • 自动检测域名，自动匹配 IndexNow 的 host 字段
  • 提交前预检密钥文件是否真的托管在站点上（避免被 403 拒绝）
  • 网络抖动自动重试（TLS 中断、超时等）
  • 分批提交，支持并发

前置准备

根据 Bing IndexNow 官方指南，配置分为四步：

1. 获取密钥

也可以自行生成密钥，要求（官方规范）：

  • 长度：8-128 个字符
  • 字符集：小写字母(a-z)、大写字母(A-Z)、数字(0-9)、连字符(-)

2. 托管密钥文件

必须将密钥文件托管在站点上，搜索引擎会抓取该文件以验证域名所有权。

Option 1：托管在站点根目录（推荐）

把密钥存成文本文件，文件名 = 密钥 + .txt，内容 = 密钥本身，上传到站点根目录。

例如密钥是 f57e273e7d004be28fcedd87d7c6341a，则：

  • 文件名：f57e273e7d004be28fcedd87d7c6341a.txt
  • 内容：f57e273e7d004be28fcedd87d7c6341a
  • 访问地址：https://你的域名.com/f57e273e7d004be28fcedd87d7c6341a.txt

Option 2：托管在站点其他位置

也可以将密钥文件托管在站点的其他路径下，例如 https://你的域名.com/myIndexNowKey.txt。这种情况下，提交时需要通过 keyLocation 参数指定文件位置。

4. 验证提交结果

提交后可通过 Bing Webmaster Tools 查看搜索引擎是否成功接收了你的 URL。

先预览不实际提交可添加参数（–dry-run）：

命令参数

参数 说明
--dry-run 模拟运行，不实际提交
--batch N 每批 N 条（默认 50，IndexNow 上限 10000）
--workers N N 个并发（默认 1 串行）
--urls URL1 URL2 ... 手动指定 URL，跳过 sitemap
--sitemap URL 指定 sitemap 地址
--host your-site.com 指定域名
--key 你的密钥 直接传密钥，跳过文件查找
--key-dir PATH 密钥文件目录（默认当前目录）
--verbose / -v 显示每个 URL 和完整请求/响应

也可用环境变量：INDEXNOW_HOST、INDEXNOW_SITEMAP、INDEXNOW_KEY、INDEXNOW_KEY_DIR。

工作原理

  1. 从当前目录读 .txt 密钥文件（文件名是 32 位十六进制即密钥本身）
  2. 拉取 sitemap.xml，递归提取所有 URL
  3. 从 URL 自动推断域名作为 IndexNow host
  4. 预检：访问 https://你的域名/密钥.txt，确认内容包含密钥（不通过则中止，避免 403）
  5. 分批 POST 到 https://api.indexnow.org/IndexNow
  6. 输出每批结果

常见问题

问题 解决方法
返回 403 / 提示密钥验证未通过 密钥文件没正确托管。检查 https://你的域名/密钥.txt 是否可访问、内容是否就是密钥本身。
SSL / TLS 错误 脚本已内置重试（最多 4 次，指数退避），偶发抖动会自动恢复。持续失败检查网络。
返回 429 提交太频繁，触发限流。脚本会自动重试；建议拉长提交间隔或减少并发。
返回 422 URL 不属于 host 字段指定的域名。检查 sitemap 里的 URL 是否都是你的域名。
