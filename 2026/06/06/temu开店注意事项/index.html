Temu开店攻略

发表于2026-06-06|更新于2026-06-06|生活
|阅读量:

该篇文章注意事项完全基于全托管方式，不适用半托管方式。

开店准备与账号注册

注册账号基础规则

  • 注册账号没有“流量等级”选项，只有规则差异。
  • 个人商户绑定的银行卡必须为本人；营业执照商家需绑定法人银行卡。
  • 退货收货地址必须设置为能正常收货的地址。平台抽检不通过的货物会被退回，注意货款和罚款。若货盘支持，可申诉避免损失。国外客户如果退货不会发送到指定地址，弃货更划算。

保证金与店铺模式

模式子模式 / 保证金特点
全托模式
（关店可退）		 VMI现货模式
保证金：1000元		 提前备货到Temu官方仓库
JIT模式
保证金：5000元		 先出单，后发货（推荐）
半托模式 Y2 / 自营/联营 不适合新手

💡 建议：新手优先选择 全托 + JIT模式，保证金提交5000元，灵活且风险可控。

店铺IP隔离

  • 对多店铺卖家，必须做IP隔离，防止一个店铺被封禁影响其他关联店铺。

产品上架核心规则

类目准入（高频罚款区）

✅ 可自主上架（无需报白）

  • 普通家居小百货、无电布艺、普通非金属配饰、简易日用小商品。

❌ 必须报白（资质审核通过才可上架，私上=下架+扣款）

  • 3C类：充电宝、数据线、锂电小家电
  • 美妆日化：护肤品、彩妆、洗护、牙膏
  • 母婴类：婴童餐具、奶嘴、婴幼儿贴身服饰、婴童玩具
  • 管控品类：食品、保健品、贴身内衣、医疗器械

不要看到同行在售就盲目上架报白类目，平台随机巡检，无证上架会冻结货款。

产品分类与命名

  • Temu产品分类并不十分清晰，类目大差不差即可。
  • 涉及IP产品（如iPhone手机壳），标题必须用 “for” 字样（例如 for iPhone），严禁直接写“iPhone”。

产品材料要求

  • 必须包含材料信息。
  • 材料中不允许含黄金、贵金属，银可以。

产品图片硬性规范（链接下架高发原因）

项目 要求
图片数量 至少5张，最多10张
图片尺寸 800×800像素
禁止内容 中文、水印、国内联系方式、二维码、厂家地址、亚裔模特、白边（大片空白）
品牌/版权 无授权不得使用logo、影视/动漫/名人印花、球星肖像；禁止多产品拼接主图
尺寸图要求 至少一张双尺寸图：英寸（ft）+ 厘米/米；容器尺寸必须标 ml，另一单位可用 qt 或 oz

📌 注意：产品包装实物上的中文是可以的，但图片上不能出现中文。

标题红线

  • 严禁堆砌大牌关键词（如耐克、苹果），严禁跨类目无关词，否则下架。

产品属性必填项

  • 尺寸、重量、容器尺寸、颜色

知识产权红线（高额罚款+封店首要诱因）

  • 商标侵权：产品造型、印花仿国际潮牌/奢侈品牌，外观近似也会被投诉扣款。
  • 版权侵权：迪士尼、漫威、动漫IP、影视图案等，无官方授权一律禁上。
  • 外观专利：海外已注册专利的网红摆件、首饰、数码配件，仿款上架需承担客户索赔。
  • 罚金来源：Temu侵权罚金直接从商家货款扣除，大额侵权直接关店。

🚨 上架前务必自查：图片、标题、产品本身是否有侵权风险。

定价、备货与隐性成本（新手亏损核心）

定价规则

  • 商家只填报出厂供货价，前端售价由平台自主制定，商家无法控价。
  • 新手常犯错误：只核算拿货价，忽略损耗，导致报价亏本。

备货原则

  • 禁止大批量囤网红爆款。平台测款后随时砍单、下架链接。
  • 建议：小批量测款 → 数据稳定 → 再补货。

必须计入成本的隐性扣费

  • 货品破损
  • 海外客户退货拒收运费
  • 平台仓储损耗
  • 活动补贴分摊
  • 抽检不合格扣费
    …

资金提醒

  • 平台有固定结算账期。新店不建议大额垫资囤货，防范现金流断裂。

产品合规认证与物流禁品

注意资质办理，比如需要卖到德国，需要办理欧洲代理，土耳其代理，德国资质

区域强制认证（缺认证 = 整批拒收，货损自负）

站点 强制认证
美国站 带电产品：FCC；婴童产品：CPSC；接触餐具：FDA …
欧盟站 CE、RoHS、REACH环保认证 …

禁售/慎发品类

  • 高压喷雾、液体灌装、强磁、易燃易爆小件 → 平台禁售 + 跨境物流拒收。

售后与平台处罚细则

  • 缺货罚则：接单后无法按期发货，按订单比例罚款。频繁缺货会限制店铺上新、降低流量权重。
  • 品质管控：单品集中差评，平台可全店下架同类SKU，永久无法报名促销活动。
  • 错发漏发：所有客诉赔付成本由商家承担。

上架前标准化自检步骤（实操落地）

  1. 核对准入：查看平台禁售名录、类目报白清单，确认品类是否可上;确认目标市场（如欧盟、美国）所需认证（CE、FCC、FDA等）及代理（欧代、英代、土代）是否齐全，报白类目是否已审核通过。
  2. 侵权自查：全链接（图片、标题、产品本身）排查商标/版权/外观专利风险。
  3. 成本核算公式：
    供货报价 = 产品拿货价 + 国内打包物流费 + 损耗罚金预留成本 + 其他隐性扣费
  4. 新店策略：多SKU小单量测款，不重仓单一产品。
